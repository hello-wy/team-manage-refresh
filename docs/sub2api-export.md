# Sub2API 导出

Team 管理的单个、批量推送共用同一导出流程。

1. 检查 Team 状态并尝试正常刷新凭证。凭证失效或缺少 Refresh Token 时，使用账号池保存的母号密码和 2FA 自动登录。
2. 校验登录邮箱和目标工作区，将新凭证加密保存到 Team；重新检查 Team 状态。
3. 实时读取成员列表并同步母号授权。同一次请求会读取新建或更新后的授权记录，再生成导出 JSON。
4. 获取 Sub2API 当前可用的 OpenAI 分组。指定分组模式下，自动从系统配置移除不存在或已停用的分组，并记录移除和保留的 ID。
5. 使用剩余有效分组创建账户，成功后记录目标账户 ID 和导出时间。

密码或 2FA 缺失、登录失败、工作区不匹配等情况会明确报告该 Team 的错误，批量处理继续执行其他 Team。无法确认账户创建结果时，保留“不确定”错误，不自动重复创建账户。

指定分组全部失效时，会保存清理后的空列表并明确要求重新选择分组，不自动改成全部分组。分组查询失败时保留原配置；配置清理保存失败时不会创建账户。

本行为随导出操作执行；需要账号池中保存有效的母号密码和 2FA。
