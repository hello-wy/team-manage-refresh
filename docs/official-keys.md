# 官key 管理

后台导航的「官key 管理」页面用于新增、编辑、删除账号与对应的官方 API Key。
列表省略显示 Key，可点击「复制」获取完整内容。账号可以是邮箱或任意账号名称，同一账号可保存多条 Key。
API Key 使用系统现有的加密密钥加密存储；启动时自动创建独立的 `official_keys` 表。

## 到期时间

到期时间按账号匹配工作台 Team 的邮箱（忽略首尾空格及大小写），使用 Team 的 `expires_at`，与工作台共用展示组件。
这是工作台的「到期时间」，与「续费时间」`renews_at` 不同。读取列表时直接使用最新的工作台数据。
没有可用时间时，可通过「设置时间」手动保存或清除，时间按北京时间填写。
同账号多个 Team 的有效到期时间不一致时，页面会明确提示并允许手动设置，不会任意选择一个 Team。
工作台恢复提供唯一时间后，优先显示工作台时间。
手动时间单独保存在 `official_key_expirations` 表，启动时自动创建，不需要修改已有官key表。
对外 `/api/official-keys` 返回格式保持不变，仍包含完整 API Key。

## 一键导出到 Sub2API

点击列表上的「一键导出到 Sub2API」导出全部已保存记录，也可以点击行内按钮单独导出。
新增、编辑和保存不会自动导出。批量导出逐条显示进度，失败记录显示具体错误，其他记录继续导出。

导出复用系统中心配置的 Sub2API 地址和管理密钥。每次读取目标站点中名称完全等于
`官key` 的 OpenAI API Key 账号作为配置模板，复制接口地址、模型映射、代理、并发、
优先级、倍率、到期设置及功能配置；模板自身的 Key、用量和探测结果不会复制。
新账号使用当前记录的 API Key，名称为 `官key ` 加记录中的邮箱/账号名，
固定绑定目标站点的分组 ID `56`，通过 `GET /api/v1/admin/groups/56` 读取并校验其为已启用的 OpenAI 分组。分组改名、同名分组或名称中的大小写和空格均不影响导出。
此流程不使用 Team/OAuth 导出分组、默认并发或 Codex 指纹设置。

首次成功后将目标站点、账号 ID、导出时间保存在独立的 `official_key_exports` 表。
重复导出更新原目标账号；编辑记录后列表显示「有修改，待同步」。
删除本地记录不会删除 Sub2API 账号。

模板不存在或重名，以及分组 ID `56` 不存在、停用、平台不符时明确报错，并区分「模板账号」与「分组 ID」。不会改用其他分组。
导出超时或响应缺少账号 ID 时显示
「结果不确定」，保留状态并阻止重复创建；需核对目标站点和关联记录后处理。
服务在导出期间中断时同样保留「导出中」记录，以便核对，避免自动重建。

## 对外读取接口

`GET /api/official-keys` 一次返回全部记录，按记录 ID 倒序排列，不分页。
请求必须携带 `admintoken` 请求头，其值为**当前后台登录密码**。
修改后台密码后旧密码立即失效；不需要额外设置 Token。
此接口不使用后台 Session 或系统设置中的独立 `X-API-Key` 鉴权。

```sh
# BASE_URL 为本服务地址，ADMIN_TOKEN 为后台登录密码。
curl "$BASE_URL/api/official-keys" \
  -H "admintoken: $ADMIN_TOKEN"
```

响应示例（示例内容不是真实凭据）：

```json
{
  "success": true,
  "keys": [
    {"id": 1, "account": "owner@example.com", "api_key": "example-api-key"}
  ]
}
```

没有记录时 `keys` 为 `[]`；请求头缺失或密码错误返回 HTTP 401；
管理员密码尚未初始化返回 HTTP 503。凭据仅从请求头读取，不接受 URL 查询参数。
成功响应包含 `Cache-Control: no-store`。

## OpenAI 官方余额查询

列表加载时，服务端会使用每条记录的 API Key 请求
`https://api.openai.com/dashboard/billing/credit_grants`，页面只接收余额结果，
不会把 Key 作为查询参数发送。成功结果显示可用美元余额；OpenAI 返回认证、网络或响应格式错误时，
表格会显示明确的查询失败原因，不会伪造余额。
点击列表的「刷新」会重新查询所有记录。每条查询结果独立，单个 Key 失败不影响其他结果。
余额直接使用响应中的 `total_available`，保留小数精度和负数，不使用充值总额减去费用来推算。

该地址属于未公开的 Dashboard 内部接口，普通项目 Key 可能被拒绝并要求登录会话。
此时余额列展示 HTTP 状态及隐藏密钥后的上游错误原因；不会自动切换凭据或改用费用数据冒充余额。
