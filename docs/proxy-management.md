# 代理管理与账号登录出口

管理员可从导航进入 `/admin/proxies`，集中新增、编辑、启停和检测 HTTP、HTTPS、SOCKS5、SOCKS5H 代理。代理需要包含主机及端口，可包含 URL 编码后的认证信息；数据库使用应用的加密密钥保存完整地址，页面只显示脱敏地址。编辑时留空地址会保留原认证。

## 配置与生效

在「账号出口」中按邮箱选择默认出口、服务器直连或指定代理，然后点击该行「保存」。号池账号也有「登录出口」快捷入口。同一邮箱在号池、Team 所有者及成员授权中共用配置。

路由优先级为：账号独立设置 → 本页默认登录出口 → 系统中心原有代理设置。选择直连会明确跳过其他代理；指定的节点停用、缺失、无法解密或连接失败时会报错，不会回退到直连。变更配置后，新请求会重新选择出口并重建缓存连接。已经开始的请求可能仍使用变更前的出口。

代理应用于账号自动登录、密码/2FA 验活、OAuth 授权码兑换、Token 刷新及账号的 ChatGPT 请求。浏览器手动完成的 OAuth 登录仍使用该浏览器自身网络，服务端无法改变浏览器出口。

## 检测结果

检测通过指定代理访问 `https://api.ipify.org?format=json`，记录实际出口 IP 与请求耗时，再查询 `https://ipwho.is/{出口IP}` 的国家、地区和城市。地理信息获取失败但出口请求成功时仍显示代理可用，并提示地理信息暂不可用。测试不会触发账号登录。

耗时为服务器经该代理访问出口检测服务的时间，不代表登录耗时；检测服务可达也不保证 OpenAI 服务可达。页面展示最近一次结果，不进行定时检测。需要固定登录 IP 时应使用静态出口代理，轮换代理可能在请求间切换 IP。

## 数据与部署

新增 `proxy_endpoints` 和 `account_proxy_routes` 两张表，应用启动时幂等创建；已有账号表不需要增加字段。账号路由以规范化邮箱为键，保留键 `*` 表示默认路由。被账号或默认设置引用的代理不能删除，应先调整绑定。

上线前使用 SQLite backup 创建一致性备份，并给旧镜像增加本地保留标签。回滚旧镜像不需要删除新增表。代理认证依赖应用现有加密密钥，请与数据库一并保留原密钥。
