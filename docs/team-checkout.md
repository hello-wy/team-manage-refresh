# 账号详情充值 Team

账号号池详情中的“充值 Team”打开优惠码输入框。填写优惠码或分享链接后，点击“生成支付链接”。留空使用支付后台保存的优惠码。

服务器复用“导出 JSON”的重新登录及授权保存流程，将账号 JSON 和优惠码发送至支付项目 `/api/integrations/team/checkout`，并返回 Stripe 链接。账号须为 Personal/Free 个人免费账号；如当前空间为 Team，请先切换至个人免费空间。缺少密码、2FA、账号类型不符、鉴权或上游失败均明确报错，不自动重试。

Team 配置（工作区名称、席位、计费周期、网络地区、账单国家和币种）使用支付管理后台保存值。生成链接不会执行付款。

环境变量：

- `TEAM_CHECKOUT_BASE_URL`：支付服务 HTTPS 站点根地址，默认 `https://pay.solidapi.top`。
- `TEAM_CHECKOUT_API_KEY`：专用于联动的 Bearer 密钥，与支付服务的 `CHECKOUT_TEAM_INTEGRATION_KEY` 相同。密钥留空时操作明确返回未配置，且不启动账号登录。

浏览器只发送账号 ID、空间 ID 和优惠码。账号 JSON 和服务密钥不下发浏览器，也不写入 URL。支付服务不保存导入的账号凭据。本功能保留原有“导出 JSON”。

提交后在弹窗下方展示完整支付链接，支持直接复制，或手动点击“前往支付”在当前标签页进入 Stripe。生成过程不打开新标签页、不自动跳转。生成失败会显示具体错误；非 JSON 响应会显示 HTTP 状态码。
